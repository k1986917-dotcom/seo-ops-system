### U-009 修改旧文章和新文章成稿质量比旧版本更差

- 状态：0.9.0 代码已加强，待真实复验；不能关闭。
- 实际现象：运营者在五步流程跑到文章制作后，发现旧文修改稿和新文章成稿均出现质量退化。
- 根因：流程框架已建立，但旧文路径只有一次 AI 生成，生成前缺少联合证据复查，生成后缺少独立编辑审查；程序校验偏重字段是否存在，未强制约束自然英文、主题与 slug、允许修改范围、链接白名单、重复 URL、填充段落和虚构经验。
- 修复：旧文改为草稿与独立编辑两阶段；新旧文章都在保存前执行确定性质量闸门，只允许在调用上限内定向修订，仍失败则不生成可交付稿。元数据长度保留为编辑提示，不再把并不存在的精确 Google 字符公式当硬门槛。
- 复验要求：当前 OAuth 联合数据已经可用；分别制作一篇合格旧文和一篇合格新文，人工检查意图、事实、英文可读性、链接、修改范围和 CMS 八字段。

### U-010 调研生成中文且与现有文章重复的新主题

- 状态：已按真实 RUN #1、#5、#8–#10 与实际文章建议页复验解决（0.10.1）；继续观察新的近义表达。
- 实际证据：候选 #7“绿色与红色激光笔在演示中的可视性对比”与 CMS 文章 #46 `Red vs. Green Laser for Presentations: Why Your “Brighter” Laser Isn’t Visible` 实质重复，却仍进入了新文章制作。
- 根因：AI 候选语义字段没有统一语言；旧去重主要依赖原始字符串/局部词重合，未充分规范中英文主题表达，也没有在写入前同时检查当前 CMS、历史候选和本轮候选。
- 第一轮修复：所有读者可见候选语义字段统一自然英文；含中文或中英混杂的候选直接丢弃；加入规范别名、停用词和三层去重，并以真实红绿激光演示主题建立回归。
- 真实复测追加发现：只看标题/摘要仍会把旧文章正文小标题已经覆盖的子题当作新主题，也会保存偏离所选分支的相关问题；因此增加结构化小标题覆盖和分支相关性门槛。
- 复验结果：摄影与光绘 RUN #1 从 8 个候选收敛为 2 个英文独立角度；实际 `/research` 保留完整运行概况，`/opportunities` 不再出现课堂激光笔、6 个已覆盖/偏题候选或中文主题。
- 0.10.0 二次修复：新增需求/缺口/页面材料三类资格门和最接近旧文关系。真实收纳 RUN #5 的唯一 DIY 线索没有搜索需求 evidence，且正文职责已由收纳指南覆盖，因此归入旧文而不是新建 URL；本轮新文章为 0。
- 0.10.1 发现修复：SerpAPI 分散到多个前沿，Tavily/Firecrawl 跨查询轮询并保存精确 lineage；分支门保留 `laser` 站点锚点，产品规格不再冒充文章覆盖。真实 RUN #10 严格重判后得到 1 个合格新主题、5 个待补证据和 13 个重复/偏题结果；泛演示错误被阻断。
- 局限：当前是可解释的规范词与结构化覆盖规则，不是完整语义模型；新的真实漏判仍需登记，而不能假定永不重复。

### U-011 GSC OAuth 自动匹配到单页属性

- 状态：已按真实根站点同步复验解决（0.9.0）。
- 实际现象：账号同时拥有根站点和 `https://laserpointerhub.com/p-B017.html/` URL-prefix 属性；首次自动连接选中单页，结果只有 23 条汇总、0 条联合行。
- 根因：旧属性评分只比较域名、HTTPS 和权限，根路径与单页路径同分后由字符串排序决定。
- 修复：自动选择只接受 domain property 或 URL-prefix 根路径；同步前再次拒绝任何已保存的子路径/单页属性。
- 验证：错误导入已按治理规则删除并保留同步审计；真实根站点同步得到 542 条汇总与 1,188 条 query + page 联合行，导入页实际显示正确根属性。

### U-012 开放调研被自动分支收窄，候选数量又被同意图换说法虚高
