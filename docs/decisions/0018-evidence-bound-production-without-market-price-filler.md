# ADR-0018：证据边界的统一制作与非市场化写作

- 状态：Accepted
- 日期：2026-07-18
- 复查：2026-10-18

## 背景

新文章已有材料确认，但旧文章可以只凭 query + page 联合指标直接进入 AI。这能证明页面上的
查询信号，却不能为新增事实、案例或改写段落提供写作材料。旧工作流中的市场、价格、Quick
Specs 和 CTA 也会把篇幅和产品推销误当成信息增量。

当前 CMS 回放还确认“铜 vs 铝壳散热”已在多篇现有文章直接讨论。保留它为待补证据的新主题会
诱导重复研究和重复 URL。

## 决定

1. 新旧文章统一使用 A、C–H 的可追溯材料包；A、E、G、至少两个来源及敏感主题的官方/研究
   来源是制作前门槛。旧文章仍额外要求当前 query + page 联合证据；click-loss 还要求上一窗口。
2. 素材包和提示词不再包含市场规模、价格、竞品报价或零售商比较。成稿与确定性检查禁止价格、
   折扣、排行榜、Quick Specs 和 CTA 作为内容填充；产品链接只在帮助完成明确任务时使用。
3. 旧文章提示词必须以当前正文、查询—页面证据和确认材料为边界，保留原 Slug 与主要意图，并
   以最小充分修改为原则。确定性检查拦截泛化锚文本、标题跳级、长段落和无证据的第一手经验。
4. 当当前 CMS 正文已覆盖一个自然语言研究假设的主意图或核心比较时，撤回该假设；不得以“补
   证据”为名继续为该主题争取新 URL。

## 后果

- 旧文章的质量门更高，某些只有 GSC 指标的任务会停在素材补充阶段；这是防止 AI 用常识填空的
  必要代价。
- 文章不再以市场或促销组件凑篇幅，产品页和内链仍可作为与读者任务相关的行动路径。
- 这不是排名效果证明。真实效果仍须由后续 GSC/CMS 导入观察，不能从结构检查推断流量增长。

## 失效与复查条件

- 已确认材料仍反复无法支持真实旧文修改，或门槛系统性阻塞有价值的低风险编辑。
- 运营者决定重新引入有明确来源和页面职责的价格/市场内容类型。
- 实际成稿复验发现质量检查无法拦截虚构事实、链接或主题漂移。
