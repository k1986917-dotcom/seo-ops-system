# ADR-0004：外部数据按角色接入，密钥保存在本地环境文件

- 状态：Accepted
- 日期：2026-07-14

## 背景

只使用 GSC/CMS 会缺少真实 SERP、季节性和外部页面证据；但把搜索 API、网页抓取器、研究搜索和 AI 当成可互换来源，会产生虚假的多来源置信度。系统还需要让单人运营者在网页中配置供应商，而不能把密钥写进代码或数据库。

## 决策

- SerpAPI 负责指定市场的 SERP 与 Google Trends 接入。
- Firecrawl 负责抓取已经选定的网页，不作为需求或排名信号。
- Tavily 负责发现候选资料，不作为 Google SERP、搜索量或权威性证明。
- AI 只综合带 evidence ID 的材料，不把模型回答当外部事实源。
- 来源一致性按独立性、直接性、质量和新鲜度评估，不按工具数量累计。
- 网页设置写入项目 `.env`；权限设置为 `0600`，文件由 Git 忽略。
- 页面只显示 `configured`，不显示掩码尾号或任何密钥字符。
- 连接测试只调用免费账户/用量/模型列表接口，并对白名单字段做最小化保存。
- 本地设置 POST 拒绝非 localhost Origin。

## 结果

单人运营者可以在一个页面配置 AI 和外部来源，核心系统仍能在未配置时降级运行。`.env` 适合当前本机 WSL，但不是加密凭据库；如果未来对外提供服务，必须另做身份认证、HTTPS、OS/云密钥管理与凭据轮换。

“连接成功”与“证据已经参与决策”分开。外部结果进入机会审核前，仍需实现响应快照、哈希、成本记录、参数口径与 evidence ID。
