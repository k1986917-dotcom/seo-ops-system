# ADR-0015：前沿优先的新主题发现与精确证据链

- 状态：Accepted
- 日期：2026-07-17
- 复查：2026-10-17

## 背景

ADR-0014 的资格门能阻止无需求、无正文材料和旧文已覆盖的候选，但真实“收纳与保护”
运行也证明：资格门正确不等于发现阶段足够有效。旧编排会把 SerpAPI 预算用于同一宽泛
查询的 SERP + Trends，把 Tavily 预算集中在第一组泛化 PAA，再把 Firecrawl 预算集中抓取
同一资料查询的前三个结果。这样即使存在新方向，也可能在形成完整证据链前被耗尽预算。

## 决策

1. 不降低 `candidate_qualification` 的需求、缺口和材料门槛；发现阶段与资格阶段继续分离。
2. 主题缺口和边界扩展先生成最多四个具体前沿查询。有限 SerpAPI 预算先覆盖不同查询；
   只有单个查询仍有第二次预算时才补 Trends。
3. 对图谱/边界入口，Tavily 先逐条搜索已经取得 SERP 的前沿查询，再轮询 PAA/相关搜索；
   GSC 入口继续优先为真实 PAA 补来源。单个 SERP 的问题列表不得独占资料预算。
4. Firecrawl 对不同 `source_discovery` 结果按名次轮询：先抓每个资料查询的第一条，再抓
   第二条。来源发现和页面采集保存 `input_refs`，候选只附加其明确引用的资料查询所产生
   的页面正文，不能沿同一宽泛 SERP 吞入无关材料。
5. 精确 PAA 在同时取得需求 SERP、对应资料发现和页面正文后，可以由确定性路径进入资格
   判定，不要求 AI 再次“碰巧”引用全部 ID。AI 仍可整理候选，但 evidence 引用大小写差异
   只做确定性规范化，不能接受不存在的 ID。
6. 分支相关性要求候选保留站点 `laser` 锚点并命中至少一个所选分支核心词；受控归一
   `educator / teaching / school` 为 classroom。泛演示、泛摄影等脱离站点对象的主题阻断。
7. 新文章覆盖关系只对照活动博客正文。产品仍参与主题图谱与内链判断，但产品规格文本
   不能冒充旧文章已回答某个信息意图。
8. 上轮 `needs_evidence` 候选若在新一轮取得更强且完整的精确证据，可由新判定取代；旧行
   标记为 `stale` 并保留前次版本与证据指纹。

## 后果

### 正面

- 搜索预算覆盖更多真实边界，而不是重复验证第一个宽泛方向。
- PAA、来源发现和页面正文形成可审计 lineage，材料不再因同属一个 SERP 就错误混用。
- AI 不可用时，只要精确 PAA 的证据完整，系统仍能发现并资格判定新主题。
- 产品页不会再以两个偶然重合的规格词阻断新文章。

### 代价与限制

- 前沿查询质量仍影响搜索结果；轮询提高覆盖，不保证每轮都有合格主题。
- 受控词项归一不是完整语义模型，真实边界样本仍需进入方法复查。
- 24 小时复用不消耗真实请求，但可让单轮读取的成功 evidence 数高于新请求预算；界面必须
  继续分开显示实际请求和复用。

## 真实复验

- RUN #6 因生成查询超过供应商 100 字符限制中断，修复为按词边界截断。
- RUN #8 首次发现“课堂/演示替代工具”，但正文集中在学校安全，正确保持
  `needs_evidence`。
- RUN #9 将资料和正文分散到不同前沿后采集成功，但三个有效 AI 候选被 0.50 分支阈值
  在资格前误删，由此定位并修复分支门。
- RUN #10 保存 8 个候选。最终重判得到 1 个真实合格新主题
  `Why are laser pointers not allowed in school?`；它引用真实 PAA、精确资料搜索和页面正文，
  且当前 65 篇博客未覆盖该主要意图。泛“presentation mistakes”被站点锚点阻断，
  PowerPoint 虚拟指针保留为待补需求事实，不因产品规格文本误判为旧文覆盖。

## 被否决的方案

- 降低需求或页面材料门槛来换取更多新主题：会把发现不足伪装成资格通过。
- 只增加 API 数量：旧编排仍会把更多预算集中到同一方向。
- 让 AI 自由补充证据关系：无法审计，并可能把无关正文拼到候选上。
- 用产品页阻断信息文章：产品存在不等于该搜索任务已有完整文章答案。
