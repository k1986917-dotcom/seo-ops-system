# ADR-0014：新文章资格门与旧内容归类

- 状态：Accepted
- 日期：2026-07-17
- 复查：2026-10-17

## 背景

调研发现的相关搜索、论坛讨论和资料页面只是线索。旧流程把“发现了资料”和“值得新建
URL”混在一起，既可能把现有文章已经覆盖的子题再次推荐，也可能把没有真实搜索需求的
论坛话题送入文章制作。单纯提高词项重叠阈值又会漏掉新方向。

## 决策

1. 五步主流程不变；调研候选在进入文章建议前增加独立、版本化的确定性资格层。
2. 新文章必须同时通过三类硬门：
   - 需求：事实必须引用 GSC、SERP/PAA 或 Trends evidence；Tavily 资料发现和
     Firecrawl 页面采集不能冒充需求。
   - 缺口：对照当前 CMS 最接近文章的标题、主要任务、结构化小标题和正文覆盖，确认
     是独立或相邻但未覆盖的主要意图。
   - 材料：至少两条来源 URL、两个 evidence ID，并至少有一份页面级采集；敏感主题
     还必须有官方或研究来源。
3. 最接近内容关系分为 `same_intent / covered_subtopic / adjacent / distinct /
   uncertain`。同意图或正文已覆盖的子题归入旧文章判断，不创建新 URL。
4. `uncertain` 进入人工复核。人工只能确认页面职责是独立、已覆盖或无法判断，不能补造
   缺失的需求或材料证据；确认独立后仍重新运行全部硬门。
5. 只有 `qualification_status=qualified` 且规则版本、CMS 指纹和证据指纹仍匹配的候选
   才显示为新文章建议。CMS 重新导入后自动把受影响结果标记失效并重新判定。
6. AI 只整理本轮传入的 evidence ID，不计算资格状态、不更改阈值、不自动发布。

## 后果

### 正面

- 0 个合格新主题成为正常、可解释的结果。
- 资料发现仍可宽进，但不能越过需求与页面材料门槛。
- 重复主题有明确的旧文去向；灰色主题保留人工判断，不靠提高阈值一刀切。
- 每次资格变化保留规则版本、前次判定和指纹，旧结果不能静默复活。

### 代价与限制

- 词项和结构化覆盖仍是程序推断，不是查询—页面事实，也不能完全替代人工阅读正文。
- AI 若没有引用 SERP/PAA evidence，即使论坛材料丰富也只会留在待证据或旧文归类。
- 当前没有向量语义索引；新出现的同义表达仍需真实样本驱动规则复查。

## 真实复验

在“laser pointer storage carrying protection”分支按 SerpAPI 2、Firecrawl 2、Tavily 3、
AI 1 的预算真实运行。得到 1 个 DIY 收纳盒线索；其材料门通过，但没有需求 evidence。
逐段对照现有 `Laser Pointer Case & Storage Guide` 后，强正文覆盖把它归为
`covered_subtopic`，最终新文章建议为 0，不创建新 URL。

## 被否决的方案

- 只看 AI 置信度：无法审计，也允许模型绕过资格门。
- 只提高标题相似阈值：会同时放过正文重复和误杀真实新意图。
- 为每轮强制补足新文章数量：会把内容产量误当增长结果。
- 把论坛、Tavily 摘要或页面采集当搜索需求：它们证明有人写过，不证明存在可执行需求。
