# ADR-0019：意图去重优先的主题发现

- 状态：Superseded by ADR-0020
- 日期：2026-07-18
- 复查：2026-10-17

## 背景

原资格规则要求每个新文章候选同时具备需求、内容缺口和页面材料。它能避免把线索冒充事实，却也把尚处探索期、但与现有内容主意图不同的细化方向全部隐藏。旧工作流的 plan 阶段先保留集群缺口、痛点、价值、历史拒绝和蚕食风险等信号，再把它们转为待研究的角度。

## 决策

1. `candidate_qualification 1.0.0` 的硬门为：范围与语言合规、清晰主要用户任务、非 `same_intent`、非 `covered_subtopic`。`uncertain` 仍须人工复核。
2. GSC/SERP 需求、来源和页面材料继续单独存储；它们承担事实与写作准备角色，不再否决一个已确认不重复的方向。内容制作仍遵守素材确认、来源可追溯和事实边界。
3. 未登记结构化假设的分支按旧 plan 的多视角方法产生多个检索种子。种子仅用于 SERP 发现，不能直接成为文章标题或需求事实。
4. 不以内容数量、搜索量、收入或转化作为放行理由；系统仍不主张查询—页面归属，且不得自动发布。

## 后果

- 运营者能看到相邻但独立的细化方向，而不会因为尚未凑齐写作材料而误以为系统没有发现。
- 建议卡可能处于低准备度，必须在制作阶段补齐可追溯素材；它不是可直接发布的承诺。
- 意图/正文比对仍是程序推断，灰色关系需人工阅读最接近文章。

## 失效条件

- 如果实跑显示相邻方向普遍与正文重复，应收紧覆盖模型或加强人工复核，而不是恢复对所有候选的材料否决。
- 如果探索种子持续产生无关 SERP，应按真实样本调整维度措辞与站点锚点。
