# ADR-0016：自然语言假设发现、运营范围与精确旧文覆盖

- 状态：Accepted
- 日期：2026-07-17
- 复查：2026-10-17

## 背景

ADR-0015 已把外部请求分散到多个前沿，但前沿仍由“分支标签 + 通用提示词”机械拼接。
真实对照显示这会产生不自然的检索式，并让分支词项门错误排除高价值的相邻任务。另一个
反例是高功率光束终端：旧文标题中的 high-power 和 beam 足以触发覆盖阈值，但正文没有明确
回答终端选择，程序不能把这种泛词重叠当作已覆盖。

## 决策

1. 五步工作流与需求、缺口、材料三类资格门不变。主题缺口和边界入口先从覆盖地图、历史
   查询和已登记的自然语言假设选择未验证问题；假设只决定要搜索什么，不是需求、事实或
   新文章资格。
2. 分支相关性保留 laser 站点锚点和与分支的核心场景关系，但不要求标题重复静态标签词。
   无法确认的关系交给资格门和人工复核，不用字面词项先行删掉。
3. 学校、课堂和未成年人场景，以及明显伤害、武器化或破坏性用途不进入本站运营候选；
   高功率本身不是禁区。该范围属于运营可执行性与品牌风险规则，2026-10-17 复查。
4. 技术候选判为 `covered_subtopic` 前，除了通用领域词重叠，还必须在现有博客标题、小标题
   或正文命中其特定技术对象。缺少该命中时归为 `uncertain`，由人工对照最接近旧文。
5. 需求、材料齐全且与旧文同主要意图的候选创建 `research_existing_content_gap` 旧文优化
   建议。映射依据保存的 CMS 意图比对，明确不声称存在 GSC query-to-page 关系。

## 后果

### 正面

- 系统能从已覆盖主干旁探索真实细分方向，而不降低资格门来换数量。
- 既有主题不会浪费：同意图线索可进入旧文行动；真正已覆盖的子题不强制产生无价值更新。
- 高功率安全主题可以被研究，但学校/未成年人和明显滥用用途不会进入生产队列。

### 代价与限制

- 假设库需要按真实运行结果维护，不能把当前样本当作完整市场矩阵。
- 词项和正文命中仍不是完整语义理解；技术比较和高风险主题的灰色结果必须人工复核。
- 外部证据支持的是采集时的需求和材料，不支持查询级转化、收入或 GSC 页面归属结论。

## 真实复验

- 隔离库的用途分支实际请求 SerpAPI 2、Tavily 2、Firecrawl 2，保存 8 个候选：
  `How to Use a 405nm Laser Pointer for Fluorescent Minerals` 和
  `Are Laser Pointers Safe for Dogs and Other Pets?` 同时通过需求、缺口和材料门；其余 6 项
  保持 `needs_evidence`。
- 高功率安全分支实际请求三个外部来源各 1 次。光束终端主题没有被范围规则阻断，因泛词
  重叠但特定对象不明确而正确进入 `needs_human_review`；Class 3R 安全主题归为旧文覆盖。

## 被否决的方案

- 为了增加新 URL 而降低页面材料或旧文缺口门槛：会把未验证线索伪装成合格主题。
- 全面禁止高功率主题：与运营范围不符，也会阻断安全和维护类真实任务。
- 用分支标签的字面匹配决定所有方向：会把新受众、用途和技术细分误删。
