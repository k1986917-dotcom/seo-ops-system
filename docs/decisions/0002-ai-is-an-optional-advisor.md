# ADR-0002：AI 是可选顾问，不是决策事实源

- 状态：Accepted
- 日期：2026-07-14

## 背景

研究、解释和写作适合大模型，但历史系统出现过 AI 为高风险候选包装角度、覆盖程序评分和模板化制造 E-E-A-T 信号的问题。

## 决策

- AI 只通过后端 Provider 调用，密钥不进入浏览器。
- 第一版支持 OpenAI-compatible API；供应商实现可替换。
- AI 读取已有证据并输出结构化解释、brief 或草稿。
- AI 不修改指标、规则、资格门槛和分数，不自动发布。
- AI 运行记录 provider、model、prompt hash、输入 evidence ID 与输出。
- 未配置 AI 时系统降级为确定性模式，而不是无法启动。

## 结果

系统可以使用先进模型，同时避免模型可用性、费用和幻觉成为核心分析的单点故障。
