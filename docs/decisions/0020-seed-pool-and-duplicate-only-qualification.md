# ADR-0020：种子池、公开语言代理与纯重复资格

- 状态：Accepted
- 日期：2026-07-18
- 取代：ADR-0019
- 复查：2026-10-17

## 背景

`candidate_qualification 1.0.0` 已把需求和材料从新文章资格硬门移出，但仍保留范围、语言、明确 intent 和关系不确定等门槛；边界分支也容易把最终候选锁在种子词项上。真实隔离调研显示，长分支标签会扩大 SERP 噪声，而有效的新奇角度（例如树艺师用激光笔指示具体树枝）可能不复述“construction / professional”等种子词，却仍以激光笔为核心并承担独立用户任务。

本站目前没有可确认的第一方评论、客服问句或订单语言。其他激光笔网站、论坛、评论和问答可以提供真实公开措辞，但证据归属必须与第一方反馈分开。

## 决策

1. `candidate_qualification 1.1.2` 只有两种硬阻断：候选与活动博客承担相同主要意图，或活动博客正文已经结构化回答该子题。关系不确定不是重复证据，范围、语言、占位 intent、需求强度和材料数量均只作诊断或制作准备度。
2. 种子负责把研究带到新证据附近，不负责锁死最终角度。候选只要仍以激光笔为核心工具，就可以跨受众、场景、边界维度或原分支词项；只有核心对象确实被激光水平仪、切割机等替换时才软降权，不改变重复资格。
3. 无结构化假设的分支复用旧 Plan 的问题链。每轮至少保留一个确定性任务种子；第二条问题链叠加 `forum reviews questions`，来源类型记录为 `public_third_party_language_probe`。
4. 公开第三方语言只能标为市场代理。它可以来自其他站点、论坛、评论、FAQ 或 Q&A，不能写成本站用户反馈、客户原话或第一方需求事实；信号弱时仍可保留低置信候选。
5. PAA、Related Searches、搜索结果标题和 Tavily 直接查询是扩展器或原始线索，不直接成为文章推荐。它们与页面采集一起交给 AI；AI 只能引用本轮 evidence，最多包装 1–4 个有独立信息增益的角度，允许返回空数组。
6. 文章建议页只显示可执行的最终选择：`synthesized_angle` 进入新文章栏，`update_existing` 自动进入旧文章栏。`raw_lead` 的 URL、原话和后续查询进入来源观察续池，供下一轮自动选作种子，不再要求人工拒绝或在文章建议页逐项处理；`covered_existing` 只保留重复审计。
7. 旧 Plan 的历史接受/拒绝与偏好只进入软排序，不隐藏候选。需求、来源数、页面材料和敏感主题官方来源继续影响置信度与写作准备；安全、法规、功率等主题在制作前仍须补可靠来源。
8. 系统不声称外部公开语言属于本站页面，不推断查询级转化或收入，也不因弱信号自动发布。

## 后果

- 小众市场不再因为证明信号少而显示“什么都没有”，运营者能看到不重复但准备度不同的细化方向。
- 新奇角度不会因跨出导航分支词项被误罚；同时，真正替换核心产品的结果仍会显示偏移诊断并降低排序。
- 原始 PAA 噪声仍被保存以便复用，但不会与可执行文章建议混在一起。
- 旧规则遗留的 `needs_evidence` / `needs_human_review` 在读取文章建议时无外部调用地按当前重复唯一规则重判，必须落到新文章、旧文更新或重复审计，不能形成不可见的人工队列。
- 公开第三方措辞扩大种子来源，却不会制造本站第一方用户语言。

## 失效条件

- 若真实多轮样本显示公开语言探针持续只返回无关产品，应按主题分支调整简短 focus 或替换探针措辞，而不是恢复材料/需求硬门。
- 若 `same_intent` 或 `covered_subtopic` 误判率升高，应增强标题、H2、正文与人工对照，不得用搜索量或来源数量替代内容重复判断。
- 若成型角度长期只复述 PAA/标题，应加强 evidence lineage 与 AI 包装约束，必要时允许该轮输出空结果。
- 若未来获得可追溯的本站评论、客服或调查数据，应新增明确的第一方来源类型，不与 `public_third_party_language_probe` 混用。
