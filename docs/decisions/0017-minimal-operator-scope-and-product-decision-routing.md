# ADR-0017：最小运营范围与产品决策路由

- 状态：Accepted
- 日期：2026-07-18
- 复查：2026-10-17

## 背景

ADR-0016 将学校/未成年人以及明显伤害、武器化或破坏性用途同时作为主题范围禁区。运营者
明确要求只保留学校/课堂和未成年人禁区；高功率、技术、户外、专业和其他成人主题不应因预设
词项自动消失。

同一轮隔离复验还发现另一个方法问题：没有已登记自然语言假设的分支，会把“分支标签 +
specific owner task”当作候选标题。这不是用户需求，且能在材料门补齐后形成假阳性。

## 决策

1. 主题范围的硬拦截只保留学校/课堂和未成年人。英语站点语言、清晰主要任务、真实需求、
   未覆盖缺口、可信材料和重复检查继续作为质量门，不属于业务范围黑名单。
2. 不再因高功率、技术、户外、专业、燃烧、切割或自卫等词项自动阻断研究主题。文章生产
   仍只能使用真实可追溯材料，不能把不支持的主张或操作经验写成事实。
3. 没有结构化自然语言假设的分支可以使用分支标签进行 SERP 发现，但该种子标记为
   `discovery_only`；它不能生成确定性文章候选。只有 SERP/PAA 等外部事实实际提出的具体
   用户问题才可继续进入证据和重复资格门。
4. 产品能力调研按“产品能力 × 用户决策 × SERP/PAA × 现有正文”判断去向：同意图或已覆盖
   子题进入旧文更新/产品内链；相邻且有写作材料的任务才可申请新 URL；材料不足保留补证据。

## 真实复验

- 第一轮 4 个检索：可充电电池充电、可调焦/发散、绿蓝天文可见性、光束变暗排障。每个都
  出现 PAA 或自然结果，但分别与现有充电、电池、光学、天文颜色、清洁/寿命文章同意图或
  已含子题。
- 第二轮 4 个检索：21700/18650、固定/可调焦、铜/铝散热、USB/可更换电池。前三者均有
  PAA 或专门对手页面；21700/18650、固定/可调焦和 USB/可更换电池应更新现有文章。铜/铝
  热管理与当前“铜 vs 不锈钢”比较相邻，具有产品能力与需求线索，但仍需至少两份页面级
  写作材料后才能决定是否新建。

## 后果

### 正面

- 不会因宽泛风险词项漏掉高功率和专业成人需求。
- 不会把分支命名或占位文字伪装为市场主题。
- 新主题枯竭时，系统能把真实需求路由到旧文、产品页/内链或补证据，而不是以重复 URL 维持
  发文数量。

### 代价与限制

- 放宽主题范围不等于放宽证据、原创性和质量门；零个新主题仍是有效结果。
- 产品规格只能证明本站能力，不能单独证明搜索需求、对手缺口或文章事实。
- 当前对手识别来自采集时的自然 SERP；尚未接入 Semrush Keyword Gap 的导入/API 数据，
  因此不能声称有完整关键词份额或竞争度结论。

## 被否决的方案

- 保持明显滥用词范围黑名单：与运营者已明确的最小禁区冲突，并会误伤高功率与技术主题。
- 继续用分支名拼接通用后缀：已由隔离实测证明会生成无需求语义的假候选。
- 因现有文章很多而直接停止调研：应先检验产品能力、用户决策和对手/PAA；只有这些也没有
  独立缺口时才能判定新 URL 没有当前价值。
