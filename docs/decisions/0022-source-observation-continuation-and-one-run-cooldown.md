# ADR-0022：来源观察续池与单轮语义冷却

- 状态：已接受
- 日期：2026-07-19
- 规则：`multi_source_topic_research 0.13.0`、`topic-hypothesis 0.11.0`、`candidate_qualification 1.1.3`
- 证据等级：A（供应商运行记录）+ C（程序推断）+ E（公开第三方语言）+ 隔离真实外部测试
- 复查日期：2026-10-17

## 背景

ADR-0021 的静态任务卡能被调研链路消费，但不能证明“本轮真实来源 → 下轮种子”的续池闭环。运营者需要开放更多来源、保留弱信号与细化方向，并且只避免与现有文章或已有候选的主要意图重复；不再以范围、需求、材料强度或意图表述作为发现期硬门。

同时，上一轮若集中在电池等方向，下一轮应优先看别处，但不能把电池或任何固定大类永久排除。

## 决策

1. 新增 SQLite v12 `research_seed_observations`。每条观察保存来源类别、URL、标题、公开摘录、evidence ID、后续查询、可选任务卡字段、语义簇、核心对象诊断与消费状态。
2. 一轮调研先同时采集 SERP/PAA/相关搜索与公共来源探针；探针覆盖论坛/社区、评价、社媒/视频、商业/竞争候选页和官方/参考页。实际 URL 决定来源类别，计划查询标签不冒充来源事实。
3. AI 只能从输入 evidence 中提取含逐字可核对摘录的来源观察；无法在原文中核对的角色、任务、条件或临时题目一律置空。无 AI 时，PAA 与资料发现的原始语言仍可保存为低结构观察。
4. 下一轮优先选择未消费的来源观察，并保留旧 Plan 的任务卡和问题链作为补足。来源多样性是排序因素，不是必须凑齐的列表；覆盖检查表也不是白名单，未知方向保留为 `emerging`。
5. 仅立即上一条已完成运行的“主攻语义簇”进入下一轮软冷却。主攻定义为至少两个已选种子且占本轮种子至少一半；冷却不删除候选，其他可用种子不足时仍可选择它。再下一轮只读取刚完成的一轮，不累积历史冷却。
6. 核心对象排序以来源摘录/标题为准，不能因为系统生成的查询带有 `laser pointer` 就把 LightBurn、激光瞄具、切割/雕刻等相邻或偏移对象升级为核心。核心来源先于相邻/偏移来源占据有限种子位。
7. PAA、相关搜索、标题或不足以支持具体推荐的材料继续标为 `raw_lead`；它们可作为下一轮种子但不直接“开始执行”。候选池中已存在同一“对象 + 动作 + 场景”的强重复时只去重该重复项，不把相邻但主要任务不同的方向当作重复。

## 隔离实测

最终复测复制生产 SQLite、保留导入 CMS/GSC、清除副本派生调研状态，并在副本中写入一条仅用于调度的“上一轮主攻 `battery_charging`”记录。生产库 SHA-256 在前后均为 `ec2cdd03c85918dd1b014c3446c011d148533b00a2ef2d34357209f50f45b0e6`。

- 连续两轮均为 `success`，每轮实际记录为 SerpAPI 3、Tavily 8、Firecrawl 4、AI 1；第二轮另复用 2 次 Firecrawl 页面。
- 第一轮确认继承了电池冷却，保存 24 条来源观察，来源覆盖商业/竞争候选页、论坛、评价、社媒/视频、官方/参考和 PAA/相关搜索；得到树艺师从地面指示修枝位置这一成型新角度。
- 第二轮继承第一轮的 `use_case_tasks` 冷却，并实际从前一轮观察中取用 3 个带来源的种子；得到“户外光束看似突然停止的原因”和“天线/机械对准中的激光笔用途”两个不同的成型角度。
- 首轮曾暴露 LightBurn 连续框选被生成查询中的 `laser pointer` 误升为核心的问题；修复为以原始摘录/标题判定锚点后重跑，最终两轮未让 LightBurn 或激光瞄具占核心种子位。树艺师近重复也被候选池重复任务去重拦下。

## 后果

- 系统能把真实公开语言续入下一轮，而不是只轮换写死卡片；但它仍不承诺小众市场每轮无限产生可发布文章。
- 对运营者可见的主题卡折叠为标题优先；原始线索与成型角度继续分开，长主题池不会迫使逐条阅读详情。
- 来源观察是公开市场代理，不是本站第一方反馈、需求事实、产品适配证明或写作材料充分性证明。
- 冷却是透明且可审计的排序机制；不能被改造成永久关键词黑名单或新的资格门。
