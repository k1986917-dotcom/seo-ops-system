## M2.5 — 主题图谱与内容边界（基础已完成）

- [x] 把 65 篇现有文章映射到稳定主题骨架，区分一个主要文章主题与多个辅助知识主题，并显示映射依据。
- [x] 可搜索、可折叠的树状界面；主题下直接链接现有文章，主视图使用简化状态。
- [x] 规范主题、别名、主父级、跨分支关联和“要做 / 不再推荐 / 暂时跳过”记忆。
- [x] 接入 GSC 信号、图谱缺口和边界扩展三个入口，新发现先去重和检查历史决定。
- [x] 可从选定主题分支继续调研；只有新受众、明显不同用途或站点目的变化需要边界确认。
- [x] 保持七个一级维度，实现受众/角色、场景/目标/生命周期、故障/限制/替代、决策/验证、产品/技术/兼容、法规/安全/地区和相邻问题的轮换研究及无结果记忆。
- [x] 保存地区、语言、意图和使用条件等横向筛选快照；筛选器不能单独生成图谱节点或文章。
- [x] 没有合格机会时允许继续外部调研、指定图谱方向或等待新信号，不强行凑卡片。

## M5 — 可选增强

- Bing Webmaster Tools 与 AI Performance。
- Merchant Center/产品数据增强。
- PageSpeed Insights / CrUX 页面体验诊断。
- GA4 或订单数据（用户实际具备时）。
- Google Trends 官方 API（用户获得 Alpha/正式访问时）。
- 多站点、身份认证和加密/托管密钥。

## 第一版明确不做

- 自动发布或自动删除。
- 自动购买第三方 SEO 数据。
- 全网持续爬虫。
- 用 pytrends 作为核心需求证据。
- 把 Tavily/Firecrawl/AI 当搜索量或排名来源。
- 伪造成功概率、收入或查询级转化。
- 用“Google 沙盒”替代可验证诊断。
- GEO/AEO/llms.txt 等未经验证的特殊 AI SEO 功能。
- 为每篇文章强制同一结构、字数、FAQ、视频或第一人称体验。
- 用 AI 检测器、同义词改写器或“去水印”分数代替事实、原创增量和编辑审阅。
