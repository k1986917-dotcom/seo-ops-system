# 路线图

## M0 — 可交接基础（完成）

- [x] 项目文档、工作日志和 ADR。
- [x] 网页骨架与本地启动。
- [x] SQLite 数据模型和增量迁移。
- [x] GSC/CMS 不可变快照与标准化导入。
- [x] AI 可选适配边界。

## M1 — 可信站点状态（进行中）

- [x] GSC/CMS 真实数据关联与导入质量。
- [x] 显示查询—页面缺失关系，不做虚假归属。
- [x] GSC 独立窗口、官方异常和置信权重门槛。
- [x] AI/SerpAPI/Firecrawl/Tavily/Trends 统一设置与安全连接检测。
- [ ] GSC 页面/查询定向导入或 API 联合维度。
- [ ] 周期快照，让当前 `provisional` 状态积累到可用。
- [ ] `external_runs`、不可变响应快照、成本和 evidence ID。
- [ ] Top 候选的 SerpAPI SERP + Trends 复核。

## M2 — 可执行机会与 Top 3（基础已完成）

- [x] 防损、站内相对 CTR、排名临界页与证据缺口。
- [x] 资格/数据质量门槛和冷启动评分。
- [x] 防损/最高价值/补证据组合，允许不足三项。
- [x] 接受和拒绝记录。
- [ ] 正文/意图级蚕食门槛。
- [ ] 执行、完成、取消和复盘页面。
- [ ] 结合外部复核的候选升级/淘汰，不让外部数据直接重算第一方事实。

## M3 — Research / Write 执行链

- 把机会转换为结构化 research brief。
- 官方/一手来源优先的证据包。
- Firecrawl 定向抓取与 Tavily 来源发现。
- 基于证据的修改建议或草稿。
- 事实引用、链接、重复内容和权限范围检查。
- 人工发布清单。

## M4 — 效果学习

- 行动基线自动冻结。
- 7/28/56 天观察。
- 页面组/查询组对比与干扰标记。
- 规则命中率、有效率和工作量回顾。
- 根据站点历史校准阈值。

## M5 — 可选增强

- Bing Webmaster Tools 与 AI Performance。
- Merchant Center/产品数据增强。
- PageSpeed Insights / CrUX 页面体验诊断。
- GA4 或订单数据（用户实际具备时）。
- Google Trends 官方 API（用户获得 Alpha/正式访问时）。
- 多站点、身份认证和加密/托管密钥。

## 第一版明确不做

- 自动发布或自动删除。
- 自动购买第三方 SEO 数据。
- 全网持续爬虫。
- 用 pytrends 作为核心需求证据。
- 把 Tavily/Firecrawl/AI 当搜索量或排名来源。
- 伪造成功概率、收入或查询级转化。
- 用“Google 沙盒”替代可验证诊断。
- GEO/AEO/llms.txt 等未经验证的特殊 AI SEO 功能。
- 为每篇文章强制同一结构、字数、FAQ、视频或第一人称体验。
