# 路线图

## M0 — 可交接基础（当前）

- 项目文档、工作日志和 ADR。
- 网页骨架与本地启动。
- SQLite 数据模型。
- GSC/CMS 不可变快照与标准化导入。
- AI 可选适配边界。

完成标准：新接手者只读文档即可运行项目、导入样例并理解下一步。

## M1 — 可信站点状态

- 首页显示数据新鲜度、导入质量和页面覆盖。
- 页面/产品与 CMS 快照关联。
- GSC 标准与对比指标完整保留。
- 显示查询—页面缺失关系，不做虚假归属。
- 基础数据质量告警。

## M2 — 可执行机会与 Top 3

- 防损、页面衰退、站内相对 CTR、排名临界页、产品页内容机会。
- 资格门槛和证据缺口。
- 冷启动评分与 Top 3 组合。
- 创建、接受、拒绝、执行、取消状态。

## M3 — Research / Write 执行链

- 把机会转换为结构化 research brief。
- 官方/一手来源优先的证据包。
- 基于证据的修改建议或草稿。
- 事实引用、链接、重复内容和权限范围检查。
- 人工发布清单。

## M4 — 效果学习

- 行动基线自动冻结。
- 7/28/56 天观察。
- 页面组/查询组对比与干扰标记。
- 规则命中率、有效率和工作量回顾。
- 根据站点历史校准阈值。

## M5 — 可选增强

- GSC API 的查询—页面联合数据。
- Bing Webmaster Tools AI Performance。
- Merchant Center/产品数据增强。
- GA4 或订单数据（用户实际具备时）。
- 多站点和权限认证。

## 第一版明确不做

- 自动发布或自动删除。
- 自动购买第三方 SEO 数据。
- 全网持续爬虫。
- 用 pytrends 作为核心需求证据。
- 伪造成功概率、收入或查询级转化。
- GEO/AEO/llms.txt 等未经验证的“特殊 AI SEO”功能。
- 为每篇文章强制同一结构、字数、FAQ、视频或第一人称体验。
